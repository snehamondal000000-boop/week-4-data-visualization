# 📊 Week 4 - Data Visualization & Capstone Project

## 📌 Project Title
**End-to-End Sales Analysis & Power BI Dashboard**

## 🎯 Project Objective
The objective of this project is to analyze business sales data using Python and Pandas, identify important business insights, and visualize the results using Microsoft Power BI.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Excel
- Microsoft Power BI
- Git & GitHub

## 📂 Dataset
The dataset contains **700 records and 16 columns** covering:

- Sales
- Profit
- Units Sold
- Products
- Countries
- Customer Segments
- Discounts
- Cost of Goods Sold (COGS)
- Date and Year

## 🔍 Data Analysis

The dataset was analyzed using Python and Pandas to perform:

- Dataset exploration
- Data type analysis
- Missing value detection
- Duplicate detection
- Business metric calculation
- Sales by country
- Sales by product
- Profit by product
- Sales by year
- Sales by customer segment

## 📈 Key Business Metrics

| Metric | Result |
|---|---:|
| Total Sales | $118.73M |
| Total Profit | $16.89M |
| Total Units Sold | 1.13M |
| Total Records | 700 |

## 💡 Key Insights

- **United States of America** generated the highest total sales among the countries.
- **Paseo** was the highest-selling product.
- **Government** was the highest-performing customer segment.
- **2014** generated significantly higher sales than 2013.
- Paseo also generated the highest product-level profit.

## 📊 Power BI Dashboard

The Power BI dashboard includes:

- Total Sales
- Total Profit
- Total Units Sold
- Sales by Country
- Sales by Product
- Monthly Sales Trend
- Country filter
- Segment filter
